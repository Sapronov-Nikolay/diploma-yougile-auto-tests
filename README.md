# Дипломная работа: Автоматизация тестирования YouGile

## 📌 Описание проекта

Автоматизация UI- и API-тестов для системы управления проектами **YouGile**.  
Проект основан на курсовой работе по ручному тестированию (Postman-коллекция, тест-план).

**Создайте и активируйте виртуальное окружение (чтобы не тащить мусор из глобалки):**

- Создание среды (Работает даже в понедельник или четверг 😉😅): `python -m venv venv`
- Вход в среду для Linux/macOS: `source venv/bin/activate`
- Вход в среду для Windows: `venv\Scripts\activate`

**Автоматизированные сценарии:**

### 🖥️ UI-тесты (6 шт)
1. **Успешная авторизация** – вход с валидными данными.
2. **Авторизация с неверным паролем** – проверка сообщения об ошибке.
3. **Создание проекта** – через интерфейс.
4. **Создание доски** – внутри проекта (проект создаётся через API для ускорения).
5. **Создание колонки** – на доске (проект и доска через API).
6. **Создание задачи** – в колонке (проект, доска, колонка через API).

### ⚙️ API-тесты (6 шт)
1. **Получение CompanyId** – POST `/api-v2/auth/companies`.
2. **Получение API-ключа** – POST `/api-v2/auth/keys`.
3. **Создание проекта (позитивный)** – POST `/api-v2/projects`.
4. **Получение проекта по ID** – GET `/api-v2/projects/{id}`.
5. **Обновление проекта** – PUT `/api-v2/projects/{id}`.
6. **Мягкое удаление проекта** – PUT `/api-v2/projects/{id}` с `deleted: true`.

## 📋 API Тест-кейсы (план работ)

| ID     | Название | Шаги | Ожидаемый результат | Статус |
|--------|----------|------|----------------------|--------|
| API-01 | Получение CompanyId | 1. Отправить POST `/api-v2/auth/companies` с логином и паролем. | Код 200, в ответе есть массив с `id`. | ✅ |
| API-02 | Получение API-ключа | 1. Отправить POST `/api-v2/auth/keys` с логином, паролем и `companyId`. | Код 201, в ответе есть `key`. | ✅ |

## 🧪 Запуск тестов и управление

- Установка зависимостей: `pip install -r requirements.txt`
- Запуск всех тестов: `pytest`
- Запуск только UI: `pytest -m "ui"`
- Запуск только API: `pytest -m "api"`
- Запуск тестов с сохранением Allure-результатов: `pytest --alluredir=allure-results`
- Просмотр Allure-отчёта: `allure serve allure-results`
- Просмотр всех API-ключей: `python key_manager.py --list`
- Очистка старых API-ключей: `python key_manager.py --clean`
- Очистка с сохранением указанного ключа: `python key_manager.py --clean --keep <ключ>`
- Проверка кода на соответствие PEP8: `flake8 .`

### 🔑 Управление API-ключами (критически важно!)
**YouGile ограничивает количество активных ключей до 30.
Без очистки тесты могут упасть с ошибкой 429 (Too Many Requests).
Для управления ключами используйте `key_manager.py` (команды выше).
Рекомендуется запускать `--clean` перед каждым большим прогоном тестов.**

### 🧹 Очистка данных
**Каждый тест, создающий проект, автоматически удаляет его после завершения
(мягкое удаление через API – `deleted: true`), чтобы не оставлять мусор. Это реализовано в фикстурах.**
